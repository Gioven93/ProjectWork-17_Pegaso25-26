# Eni | Sostenibilità e report

Pagina web statica realizzata per il Project Work del CdS in Informatica per le Aziende Digitali (L-31), traccia 17: *Sviluppo di una pagina web per il download dei report di sostenibilità di un'impresa del settore primario*.

La pagina presenta le principali attività di sostenibilità di Eni S.p.A. e consente di scaricare l'Annual Report 2025 (che contiene la Sustainability Statement 2025) e il report volontario *Eni for 2025 – A Just Transition*.

- `index.html`: struttura e contenuti (HTML5 semantico, commentato)
- `style.css`: presentazione (CSS3, layout responsive con CSS Grid, commentato)
- `images/hero.jpg`: immagine di apertura (Unsplash, licenza libera)

Nessun JavaScript, framework o dipendenza esterna. Pagina dimostrativa realizzata per finalità didattiche.
